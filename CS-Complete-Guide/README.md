## 📚 6대 핵심 분야

### 기초 핵심 (Foundation)

### 1️⃣ [자료구조 & 알고리즘](./01-data-structures-algorithms.md)

> **코딩 테스트와 면접의 핵심**

**주요 내용:**
- ⏱️ **시간/공간 복잡도**: Big-O 표기법 완벽 이해
- 📊 **기본 자료구조**: 배열, 리스트, 스택, 큐, 해시테이블
- 🌳 **트리**: 이진 트리, BST, AVL, 힙
- 🕸️ **그래프**: DFS, BFS, 다익스트라, 위상 정렬
- 🔄 **정렬**: 버블, 선택, 삽입, 병합, 퀵, 힙 정렬
- 🔍 **탐색**: 선형, 이진 탐색
- 💡 **동적 프로그래밍**: 피보나치, 배낭, LCS
- 🎯 **면접 패턴**: Two Pointers, Sliding Window, 백트래킹

**학습 시간:** 2-3주
**난이도:** ⭐⭐⭐⭐

---

### 2️⃣ [운영체제 (Operating Systems)](./02-operating-systems.md)

> **시스템의 핵심 동작 원리**

**주요 내용:**
- 🖥️ **OS 기본**: 커널, 시스템 콜
- ⚙️ **프로세스 & 스레드**: 차이점, 생명주기, 동작 원리
- 📅 **CPU 스케줄링**: FCFS, SJF, Round Robin, Priority
- 🔒 **동기화**: Race Condition, Mutex, Semaphore, Monitor
- ⚠️ **데드락**: 발생 조건, 예방, 회피, 탐지
- 💾 **메모리 관리**: 페이징, 세그먼테이션, 단편화
- 🗂️ **가상 메모리**: 요구 페이징, 페이지 교체 알고리즘
- 📁 **파일 시스템**: FAT, inode, 디스크 스케줄링

**학습 시간:** 2-3주
**난이도:** ⭐⭐⭐⭐⭐

---

### 3️⃣ [네트워크 (Networks)](./03-networks.md)

> **인터넷과 통신의 모든 것**

**주요 내용:**
- 🌐 **OSI 7계층**: 각 계층의 역할과 프로토콜
- 🔌 **TCP/IP 모델**: 실무에서 사용하는 실제 모델
- 📍 **IP 주소**: IPv4, IPv6, 서브넷 마스크, NAT
- 🚀 **TCP vs UDP**: 차이점, 3-way handshake, 사용 사례
- 📡 **HTTP/HTTPS**: 메서드, 상태 코드, SSL/TLS
- 🏷️ **DNS**: 도메인 이름 변환 과정
- ⚖️ **로드 밸런싱**: L4/L7, 알고리즘, Health Check
- 🍪 **세션 관리**: Cookie, Session, JWT

**학습 시간:** 1-2주
**난이도:** ⭐⭐⭐

---

### 4️⃣ [데이터베이스 (Databases)](./04-databases.md)

> **데이터의 저장과 관리**

**주요 내용:**
- 💾 **DB 기본**: RDBMS, 키의 종류
- 📝 **SQL**: DDL, DML, JOIN, 집계 함수, 서브쿼리
- 📐 **정규화**: 1NF ~ BCNF, 이상 현상 해결
- 🚀 **인덱스**: B-Tree, 클러스터/논클러스터, 최적화
- 🔄 **트랜잭션**: ACID, 상태, 동시성 제어
- 🛡️ **격리 수준**: READ UNCOMMITTED ~ SERIALIZABLE
- 🎨 **DB 설계**: ER 다이어그램, 관계 유형
- 🗄️ **NoSQL**: Key-Value, Document, Column, Graph

**학습 시간:** 2-3주
**난이도:** ⭐⭐⭐⭐

## 📖 각 파트 학습 방법

### 1단계: 이론 학습 (30%)
- 각 파트의 개념을 차근차근 읽기
- 이해 안 되는 부분은 유튜브, 블로그 참고
- 노트 정리 (손으로 쓰면 더 좋음)

### 2단계: 코드 실습 (40%)
- 제공된 코드 예시 직접 실행
- 변형해보며 동작 원리 이해
- 디버거로 단계별 실행 확인

### 3단계: 문제 풀이 (20%)
- 백준, 프로그래머스, LeetCode
- 각 주제별 대표 문제 풀기
- 시간 복잡도 분석 연습

### 4단계: 면접 준비 (10%)
- 각 파트 면접 질문 답변 준비
- 모의 면접 (혼자 또는 스터디)
- 설명하듯 답변 연습

## 💡 효과적인 학습 팁

### ✅ DO (해야 할 것)
- **매일 조금씩**: 하루 1-2시간 꾸준히
- **직접 코딩**: 눈으로만 보지 말고 직접 작성
- **설명해보기**: 다른 사람에게 설명하듯 정리
- **실무 연결**: "이게 실무에서 어떻게 쓰일까?" 생각
- **복습**: 일주일에 한 번씩 이전 내용 복습

### ❌ DON'T (하지 말아야 할 것)
- **몰아서 공부**: 하루 8시간보다 매일 2시간
- **외우기**: 이해 없이 암기만 하지 말 것
- **영상만 보기**: 직접 코딩하지 않으면 소용없음
- **완벽주의**: 100% 이해하려다 진도 못 나감
- **비교**: 남과 비교하지 말고 어제의 나와 비교
